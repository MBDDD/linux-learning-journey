#### 📅 ЭТАП 1: Фундамент Linux и Сети (Октябрь)

**Неделя 1 (21–25 сентября): Развертывание среды, CLI и Git**
*   **Задача:** Перестать бояться черного экрана и начать вести портфолио.
*   **Практика:**
    *   Установить VirtualBox (или WSL2), накатить Ubuntu Server 24.04 LTS. Настроить сеть «Сетевой мост» (Bridged). Подключиться к ней с основного ПК через PowerShell/SSH.
    *   **Git:** Установить Git, настроить `user.name` и `user.email`. Создать репозиторий `linux-learning-journey` на GitHub. Выучить `git init`, `git add`, `git commit`, `git push`, `git pull`.
*   **Темы:** Навигация (`cd`, `ls`, `pwd`, `mkdir`), менеджер пакетов (`apt update && apt install htop curl`), основы Git.
*   🎯 **Для резюме/GitHub:** Залить в репозиторий файл `week1_notes.md` со шпаргалкой по командам. Сделать первый коммит.

**Неделя 2 (28 сентября – 2 октября): Пользователи, права доступа и SSH**
*   **Задача:** Понять, как устроена безопасность в Linux.
*   **Практика:** Создать нового пользователя. Сгенерировать SSH-ключи на основном ПК (`ssh-keygen`). Настроить вход на сервер *только* по ключам, полностью отключив вход по паролю в `/etc/ssh/sshd_config`.
*   **Темы:** Пользователи и группы (`useradd`, `groupadd`), права доступа (`chmod`, `chown`), утилита `sudo`.
*   🎯 **Для резюме:** В блок "Навыки" добавляем: *"Настройка безопасного удаленного доступа (SSH keys), управление правами доступа (chmod, chown, sudo)"*.

**Неделя 3 (5–9 октября): Работа с текстом и редакторы**
*   **Задача:** Научиться быстро искать информацию в логах (это 50% работы админа).
*   **Практика:** Скачать большой текстовый лог-файл (например, access.log Nginx). Найти все строки с ошибкой "404" или "500", посчитать их количество и записать результат в новый файл `errors.txt`.
*   **Темы:** Vim (базовые команды: `i`, `:wq`, `:q!`), утилиты `grep`, `awk`, `sed`, `less`, `tail -f`.
*   🎯 **Для резюме:** В блок "Навыки" добавляем: *"Анализ системных логов с помощью grep, awk, sed, tail"*.

**Неделя 4 (12–16 октября): Процессы и системные службы (Systemd)**
*   **Задача:** Понять, как Linux управляет программами.
*   **Практика:** Написать простой bash-скрипт (например, вывод времени и загрузки CPU в файл). Создать для него кастомный юнит `.service` в systemd. Настроить автозапуск, научиться делать `restart`, `status` и читать логи через `journalctl -u myservice`.
*   **Темы:** Жизненный цикл процесса (`ps`, `top`, `kill`), архитектура `systemd`.
*   🎯 **Для GitHub:** Залить этот `.service` файл и скрипт в репозиторий с инструкцией, как его установить. Сделать коммит.

**Неделя 5 (19–23 октября): Сетевая подсистема Linux**
*   **Задача:** Привязать твои знания из МТС/МТУСИ к практике в Linux.
*   **Практика:** Изменить динамический IP сервера на статический через `netplan`. Настроить базовый брандмауэр (`ufw`), закрыв все порты, кроме SSH (22) и HTTP (80).
*   **Темы:** Утилиты `ip a`, `ip route`, `ss -tlnp`, `ping`, `traceroute`, `tcpdump` (базово), диагностика DNS через `dig` и `nslookup`.
*   🎯 **Для резюме:** В блок "Навыки" добавляем: *"Настройка сетевых интерфейсов (netplan), базовая диагностика сетей (tcpdump, ss, dig), настройка ufw"*.

#### 📅 ЭТАП 2: Сервисы, Автоматизация и Выход на Рынок (Ноябрь)

**Неделя 6 (26–30 октября): Веб-серверы и Базы данных**
*   **Задача:** Развернуть классический стек.
*   **Практика:** Установить Nginx и PostgreSQL. Настроить Nginx так, чтобы он отдавал твою кастомную HTML-страницу ("Привет, это сервер Ивана"). Зайти в консоль PostgreSQL, создать базу данных и пользователя.
*   **Темы:** Конфигурирование Nginx (блоки `server`, `location`), базовые команды SQL в консоли (`\l`, `\c`, `CREATE USER`).
*   🎯 **Для резюме:** В блок "Навыки" добавляем: *"Базовое администрирование Nginx и PostgreSQL"*.

**Неделя 7 (2–6 ноября): Автоматизация на Bash / Cron + Ansible (введение)**
*   **Задача:** Заставить сервер работать за тебя. Это твой главный пет-проект.
*   **Практика:**
    *   **Bash/Cron:** Написать Bash-скрипт, который каждую ночь делает резервную копию папки `/etc/nginx`, упаковывает её в `.tar.gz` архив с датой в названии и складывает в папку `/backup`. Добавить этот скрипт в `crontab`.
    *   **Ansible:** Установить Ansible на свой основной ПК (или на сервер). Написать первый `playbook`, который устанавливает Nginx на твой Ubuntu Server. Запустить его.
*   **Темы:** Переменные, циклы и условия в Bash, синтаксис `crontab`. Основы Ansible: `inventory`, `playbook`, модули `apt`, `service`, `copy`.
*   🎯 **Для GitHub:** Залить скрипт бэкапа и Ansible-playbook. Написать крутой `README.md`: *"Скрипт для автоматизации бэкапа конфигураций Nginx с ротацией по дате + Ansible-playbook для установки Nginx"*. **Это будет твой козырь на собеседовании.**

**Неделя 8 (9–13 ноября): Docker и Мониторинг (Zabbix)**
*   **Задача:** Перестать бояться контейнеров и научиться следить за инфраструктурой.
*   **Практика:**
    *   **Docker:** Установить Docker. Написать простейший `Dockerfile` для своего Python-скрипта (из прошлых опытов) или для Nginx, собрать образ (`docker build`) и запустить его (`docker run`), пробросив порты.
    *   **Zabbix:** Установить Zabbix-сервер и агент на свой Ubuntu Server (можно в Docker). Настроить базовые метрики (CPU, RAM, диск) и посмотреть, как выглядят алерты.
*   **Темы:** `docker run`, `docker ps`, `docker logs`, базовый `docker-compose`. Основы Zabbix: установка, веб-интерфейс, метрики, триггеры.
*   🎯 **Для резюме:** В блок "Навыки" добавляем: *"Понимание основ контейнеризации (Dockerfile, docker run), базовый мониторинг (Zabbix)"*.

**Неделя 9 (16–20 ноября): Закрепление и Траблшутинг**
*   **Задача:** Научиться чинить то, что сломалось (имитация собеседования).
*   **Практика:** Идти на сайт **SadServers.com** (или аналоги) и пройти 3-5 сценариев. Пытаться понять, почему не работает сеть, почему переполнен диск (`df -h`, `du -sh`) и почему падает сервис.
*   🎯 **Для резюме:** В раздел "Обо мне" добавляем фразу: *"Регулярно решаю практические задачи по траблшутингу Linux-серверов на платформе SadServers для поддержания навыков"*. (HR это обожают).

**Неделя 10 (23–27 ноября): Финальный проект, Резюме и старт откликов**
*   **Задача:** Конвертировать знания в приглашения.
*   **Практика:**
    1.  **Финальный проект:** Собери всё воедино в репозитории `my-linux-infra`. Внутри: Ansible-playbook для развертывания Nginx + PostgreSQL, `docker-compose.yml` для запуска сервисов, конфиги Zabbix. В `README.md` подробно распиши, что это за проект и как его развернуть.
    2.  **Резюме:** Обновить резюме на HH.ru, внедрив все пункты "🎯 Для резюме" из этого плана. В разделе "Проекты" со ссылкой на GitHub опиши свой финальный проект.
    3.  **Опыт работы:** Исправить опыт работы на реальные ~2 года 3 месяца (если это соответствует действительности).
    4.  **Отклики:** Начать рассылать отклики на вакансии "Младший системный администратор Linux", "Инженер технической поддержки 2-й линии", "Junior DevOps" со статусом "Готов выйти в начале декабря".
