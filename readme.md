# Начинаю изучение администрирования серверов Linux

## Навигация
- `pwd` — показать текущую директорию
- `ls -la` — показать все файлы и папки (включая скрытые)
- `cd <папка>` — перейти в папку
- `mkdir <имя>` — создать папку

## Менеджер пакетов (APT)
- `sudo apt update` — обновить список доступных пакетов
- `sudo apt install <имя>` — установить пакет
- `sudo apt upgrade` — обновить установленные пакеты

## Git (основы)
- `git init` — инициализировать репозиторий
- `git add .` — добавить все изменения в индекс (подготовить к коммиту)
- `git commit -m "текст"` — сохранить изменения с комментарием

## Базовые команды CLI

### Навигация
```bash
pwd              # Показать текущую директорию
ls               # Список файлов
ls -la           # Все файлы (включая скрытые)
cd <путь>        # Перейти в директорию
cd ..            # На уровень вверх
mkdir <имя>      # Создать директорию

Работа с файлами
cat <файл>       # Вывести содержимое файла
nano <файл>      # Редактировать файл (простой редактор)
cp <откуда> <куда>   # Копировать
mv <откуда> <куда>   # Переместить/переименовать
rm <файл>        # Удалить файл
rm -rf <папка>   # Удалить папку рекурсивно

Менеджер пакетов APT
sudo apt update              # Обновить список пакетов
sudo apt upgrade -y          # Обновить установленные пакеты
sudo apt install <пакет>     # Установить пакет
sudo apt remove <пакет>      # Удалить пакет
sudo apt search <пакет>      # Поиск пакета

Примеры:
sudo apt update && sudo apt install htop curl git -y


Git основы
Первичная настройка
git config --global user.name "mbddd"
git config --global user.email "sl_mc1@mail.ru"

Основные команды
git init                          # Инициализировать репозиторий
git status                        # Показать статус изменений
git add <файл>                    # Добавить файл в индекс
git add .                         # Добавить все файлы
git commit -m "сообщение"         # Создать коммит
git push                          # Отправить в удаленный репозиторий
git pull                          # Получить изменения из репозитория
git log                           # История коммитов


Работа с удаленным репозиторием (SSH)
# Генерация SSH-ключа
ssh-keygen -t ed25519 -C "sl_mc1@mail.ru"

# Просмотр публичного ключа
cat ~/.ssh/id_ed25519.pub

# Привязка remote-репозитория
git remote add origin git@github.com:mbddd/linux-learning-journey.git

# Отправка первой версии кода
git branch -M main
git push -u origin main

SSH и безопасность
Генерация ключей
ssh-keygen -t ed25519 -C "your_email@example.com"

Подключение
ssh user@10.13.16.36

Проверка SSH-сервиса на сервере
sudo systemctl status ssh
sudo systemctl enable ssh
sudo systemctl restart ssh
